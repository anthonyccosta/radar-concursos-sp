\# 🎯 Radar de Editais e Concursos Públicos (SP \& Região)



Aplicação web desenvolvida em Python para monitoramento automatizado, filtragem e persistência de editais de concursos públicos em São Paulo.



\## 🏗️ Arquitetura e Stack Tecnológica

\- \*\*Linguagem:\*\* Python 3.15

\- \*\*Web Scraping \& Bypass:\*\* `curl\_cffi` (emulação de handshake TLS) + `BeautifulSoup4`

\- \*\*Manipulação de Dados:\*\* `Pandas`

\- \*\*Persistência (Banco de Dados):\*\* `SQLite3` (prevenção de duplicidade via constraint `UNIQUE`)

\- \*\*Frontend / Dashboard:\*\* `Streamlit` (CSS customizado sob grid de 8px)
